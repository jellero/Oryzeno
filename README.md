# Oryzeno OpenLink

Sito statico classico pubblicato direttamente dalla root del repository.

```text
index.html
assets/
  css/style.css
  js/app.js
  img/favicon.svg
manifestazione.html
mercato.html
trasparenza.html
privacy.html
termini.html
rischi.html
cookies.html
```

GitHub Pages pubblica direttamente la root tramite `.github/workflows/pages.yml`. Non vengono usati ZIP, Base64, generatori o processi di ricostruzione.
